# 水波纹手势交互 - 设计文档

## 概述

单文件 Web 应用，HTML5 Canvas 实现水波纹模拟。暗色背景 + 水墨线条风格的极简视觉，支持点击、拖拽、滑动、多点触控，闲时随机落雨。

## 技术栈

- 单文件 `index.html`，零依赖，浏览器打开即用
- HTML5 Canvas 2D 渲染
- 纯 JavaScript，无框架

## 架构

```
渲染层 (Canvas 2D)  ←  模拟层 (波动方程)  ←  输入层 (鼠标/触摸)
                                     ←  雨滴生成器
```

## 波动方程

2D 离散波动方程，双缓冲高度场：

```
h_next(x,y) = 2*h(x,y) - h_prev(x,y) + c² * (avg(邻居) - h(x,y))
```

- 网格分辨率：约 200×200（自适应视窗）
- 双缓冲数组：current / previous，避免原地修改
- 每帧衰减系数：0.96~0.99，波纹自然消失
- 波速 c²：0.2~0.3，控制传播速度

## 渲染（极简水墨风格）

- 不直接渲染高度值，渲染**高度场的梯度**（水面倾斜程度）
- 梯度绝对值 → 灰白线条亮度/粗细
- 背景色：`#0a0a0a`
- 线条色：`#e8f0ff` 带透明度层次
- 视窗自适应（resize 事件重建网格）

## 输入

所有触碰用**高斯分布**注入高度场，形成局部凹陷：

- **点击**：单点高斯凹坑
- **拖拽**：路径上连续注入凹坑
- **滑动**：凹坑带方向性（前方略高后方略低），模拟推水
- **多点触控**：每触点独立注入，波动方程自动处理干涉

## 雨滴

- 随机间隔 1~5 秒
- 随机位置，小幅度高斯凹坑
- 比手动点击更轻更小

## 边界处理

波纹碰到边缘消失（边界吸收），不反弹。
